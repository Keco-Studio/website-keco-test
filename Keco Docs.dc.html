Quickstart

Technical documentation for building with Keco Studio. Start here to set up your first project, import game data, and run a balance check in about 15 minutes.

Before you begin

  • A Keco account. The Starter plan is enough for this guide.
  • macOS 13+ or Windows 11.
  • Optional: a spreadsheet of game data (items, units, or dialogue) to import.

1. Install Keco Studio

Download the desktop app from the homepage, or install the CLI to work from your terminal.

npm install -g @keco/cli
keco login

2. Create a project

A project holds your data tables, mechanics, and simulation settings. Start empty or from a Marketplace template.

keco new my-rpg --template pixel-map

3. Import your data

Keco reads CSV and XLSX files and keeps references between tables intact, so an item’s drop_table column stays linked to your loot table.

keco import ./data/items.csv --table items

4. Validate balance

Run simulated sessions to check progression and economy curves before anything reaches development.

keco simulate --runs 1000 --report
